# LabTechVision Web Builder

Static site: `index.html`, `logo.svg` (placeholder), `.nojekyll`.

## Publish on GitHub Pages
1. Create a repository, upload all files in this folder to the root (keep `index.html` at the top level).
2. Add your own `logo.png` beside `index.html` (it is used first; `logo.svg` is the fallback).
3. Settings > Pages > Source: Deploy from a branch > `main` / `(root)` > Save.
4. Your site appears at `https://<username>.github.io/<repo>/` within a minute or two.

Note: the in-app "Publish" button creates a demo link only; real hosting is GitHub Pages.
